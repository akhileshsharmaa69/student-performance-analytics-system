Student Performance Analytics System

Project Overview

The Student Performance Analytics System is a Python-based project that analyzes student marks and attendance using NumPy and Pandas.

Objective

The objective of this project is to calculate student performance and display useful academic information in a clear format.

Technologies Used

- Python
- NumPy
- Pandas
- CSV Dataset
- Visual Studio Code

Dataset Description

The dataset contains 30 student records with student IDs, names, marks in six subjects, and attendance percentages.

Key Features

- Displays student records.
- Calculates total marks and average marks.
- Assigns grades to students.
- Checks pass/fail status.
- Calculates class average.
- Displays subject-wise average marks.
- Identifies students with the highest and lowest total marks.
- Displays the top 5 students.
- Generates an attendance report.

How to Run the Project

1. Install Python on your computer.

2. Install the required libraries:
   
   "pip install numpy pandas"

3. Keep "main.py" and "student.csv" in the same folder.

4. Open the folder in Visual Studio Code.

5. Run the program:
   
   "python main.py"
